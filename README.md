# 🥗 Nutrition Recommender

영양성분표 기반 **제품 비교·추천 스코어링 서버**입니다.
여러 제품의 영양 정보(100g당)와 사용자의 목표(체중감량, 혈당 관리 등)를 받아서, 목표에 가장 잘 맞는 제품을 점수로 순위 매기고 추천 이유까지 만들어 줍니다.

Flask HTTP API로 제공되기 때문에 Node.js 백엔드나 프론트엔드 등 어떤 클라이언트에서도 호출할 수 있습니다.

## ✨ 주요 기능

- **목표별 프리셋 추천** – 체중감량 / 가성비 근성장 / 혈당 케어 / 붓기 방지
- **자유 서술 해석 (AI)** – "당뇨 초기예요" 같은 문장을 Gemini가 영양소별 가중치로 변환
- **키워드 폴백** – AI 호출이 실패해도(네트워크 장애, 크레딧 소진 등) 키워드 규칙으로 가중치를 대체
- **직접 가중치 지정** – 클라이언트가 가중치를 직접 넘겨 미세 조정 가능
- **누락 값 안전 처리** – OCR이 읽지 못한 값(`null`)이 있는 항목은 모든 제품에서 비교 대상에서 제외
- **추천 근거 문구 생성** – 1위 제품이 어떤 항목에서 가장 유리했는지 한글 문장으로 설명
- **내부 토큰 인증** – `X-Internal-Token` 헤더로 서버 간 호출 보호

## 🧠 스코어링 방식

1. 비교할 영양소마다 제품군 안에서 **min-max 정규화**(0~1)
2. "낮을수록 좋은" 항목(칼로리, 당류, 나트륨 등)은 값을 뒤집어 **항상 클수록 유리**하게 통일
3. 항목별 **가중치를 곱해 합산** → 최종 점수 및 항목별 기여도(`breakdown`) 계산
4. 점수 내림차순 정렬

> 모든 제품의 값이 같은 항목은 중립값 0.5로 처리됩니다.
> 제품 간 비교가 상대적이므로, 점수는 **같이 비교한 제품들 사이에서만** 의미가 있습니다.

### 지원 영양소

| 키 | 항목 | 방향 |
|---|---|---|
| `calorie` | 칼로리 | 낮을수록 좋음 |
| `sugar` | 당류 | 낮을수록 좋음 |
| `carb` | 탄수화물 | 낮을수록 좋음 |
| `fat` | 지방 | 낮을수록 좋음 |
| `saturated_fat` | 포화지방 | 낮을수록 좋음 |
| `trans_fat` | 트랜스지방 | 낮을수록 좋음 |
| `cholesterol` | 콜레스테롤 | 낮을수록 좋음 |
| `sodium` | 나트륨 | 낮을수록 좋음 |
| `cost` | 가격 (100g당) | 낮을수록 좋음 |
| `protein` | 단백질 | **높을수록 좋음** |

### 목표 프리셋

| goal | 설명 | 가중치 |
|---|---|---|
| `weight_loss` | 체중감량: 저칼로리 · 고단백 · 저당 | calorie 1.0, protein 0.7, sugar 0.6 |
| `muscle` | 가성비 근성장: 고단백 · 최저가 | protein 1.0, cost 1.0 |
| `blood_sugar` | 혈당 케어: 저당 · 저탄수화물 | sugar 1.2, carb 1.0 |
| `anti_swelling` | 붓기 방지: 저나트륨 · 저당 · 저지방 | sodium 1.2, sugar 0.6, fat 0.6 |

## 🔄 자유 서술 해석 흐름

```
health_text
   │
   ├─ 1) Gemini 해석 (temperature 0, JSON 출력 고정)
   │      └─ 가중치 0 초과 ~ 1.5 이하, 최대 4개 항목
   │
   ├─ 2) 실패 / 빈 결과 → 키워드 폴백 규칙
   │
   └─ 3) 그마저 실패 → ValueError (프리셋 선택 또는 직접 입력 안내)
```

- 항목의 **방향은 고정**입니다. 예를 들어 "단백질을 줄여야 해요"처럼 고정된 방향과 반대되는 요청은 해당 항목을 가중치에 넣지 않습니다.
- 폴백 규칙은 "싸고 단백질 많은 거"처럼 조건이 섞인 문장도 처리하도록 걸리는 규칙을 모두 합치며, 같은 항목은 더 큰 가중치를 사용합니다.

## 🧪 Python에서 직접 사용하기

```python
from nutrition_scoring import Product, score_products, explain_recommendation

products = [
    Product("과자 A", {"calorie": 250, "sugar": 12, "sodium": 450}),
    Product("과자 B", {"calorie": 180, "sugar": 5, "sodium": 300}),
]

ranked = score_products(products, goal="weight_loss")
print(ranked)
print(explain_recommendation(ranked, "weight_loss"))
```

## ⚠️ 참고 사항

- `cost`는 **100g당 가격**으로 환산해서 보내야 합니다. 패키지 가격을 그대로 넣으면 용량이 다른 제품끼리 비교가 왜곡됩니다.
- 제품이 1개뿐이면 정규화 결과가 모두 중립값이 되어 순위의 의미가 없습니다. 2개 이상 비교를 권장합니다.
- 이 서비스의 추천은 영양성분표 수치의 단순 비교이며, 의학적 진단이나 처방을 대신하지 않습니다.
